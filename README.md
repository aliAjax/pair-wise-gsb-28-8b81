# 配送任务拖拽排班

- 行业：物流
- 技术栈：React、Vite、TypeScript、dnd-kit
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 排班闭环规则

1. 新增订单进入「待分配」时必须填写配送开始时间、结束时间和重量（结束须晚于开始，重量 > 0）。
2. 把订单卡片拖到司机列即派单，校验通过才生效：
   - 同一司机相邻两单（按开始时间排序）至少间隔 30 分钟，不允许重叠；
   - 同一司机单日累计重量不得超过 500kg。
3. 超限时拒绝派单，原排班保持不变，并在该司机卡片下列出冲突订单（时间冲突的订单对）和超出重量。
4. 「配送中」的订单不可拖拽改派；改派或拖回待分配池会同步释放原司机负荷。
5. 排班与负荷保存在 localStorage（key：`hxwlfront-14-schedule`），刷新后仍在。

订单状态流转：待分配 → 已分配 →（开始配送）→ 配送中 →（完成配送）→ 已完成。
